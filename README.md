## What it does

- 🚀 **Boost FPS**: tested tweaks for Windows, your GPU, CPU and RAM.
- ⚡ **Lower input lag**: the mouse, keyboard and Windows settings that add delay, switched off.
- 📶 **Lower ping**: network tweaks and a bufferbloat fix for steadier ping.

Make a backup first, then switch on the tweaks you want. Every tweak can be switched off again.
